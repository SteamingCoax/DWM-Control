Install DWM Control on Linux

Version . Works on 64-bit PCs and on Raspberry Pi (64-bit and 32-bit OS).

1. Download

Pick the button that matches your computer. The commands below update to match your choice.

Ubuntu, Debian, Linux Mint, Raspberry Pi OS

64-bit PCIntel or AMD Raspberry Pi, 64-bit OSPi 3, 4, 5, 400, 500 Raspberry Pi, 32-bit OSolder or "Legacy" OS images

Any other Linux (Fedora, openSUSE, Arch, ...)

64-bit PCIntel or AMD 64-bit ARMPi 3, 4, 5 with 64-bit OS 32-bit ARMPi with 32-bit OS
Not sure if your Raspberry Pi OS is 64-bit? Open Raspberry Pi Imager and look at the OS you installed: 64-bit images say "(64-bit)" in the name. If it does not, it is 32-bit.

2. Install

Open the downloaded file and choose Install. Or, in a terminal in your Downloads folder:

sudo apt install ./

The package also sets up USB access to the meter, so no other steps are needed.

There is nothing to install. In a terminal in your Downloads folder, make the file executable:

chmod +x

Then allow the app to talk to the meter. Copy this once, paste it in the terminal, and enter your password when asked:

sudo tee /etc/udev/rules.d/49-dwm.rules >/dev/null <<'EOF'
SUBSYSTEM=="usb", ATTRS{idVendor}=="0483", ATTRS{idProduct}=="5740", ENV{ID_MM_DEVICE_IGNORE}="1"
SUBSYSTEM=="tty", ATTRS{idVendor}=="0483", ATTRS{idProduct}=="5740", MODE="0664", GROUP="dialout", TAG+="uaccess"
SUBSYSTEM=="usb", ATTRS{idVendor}=="0483", ATTRS{idProduct}=="df11", MODE="0664", GROUP="plugdev", TAG+="uaccess"
EOF
sudo udevadm control --reload-rules && sudo udevadm trigger

3. Start DWM Control

Open DWM Control from your application menu, or run it from any terminal:

dwm-control

In a terminal in your Downloads folder:

./

If no window appears, start it this way instead (works everywhere):

./ --appimage-extract-and-run

4. Plug in the meter

Connect the DWM V2 by USB. The meter appears on the Control tab within a few seconds.

After a firmware update, switch the meter off and on by hand. It does not restart on its own, and its name goes back to DWM_V2, so rename it from its card if you had given it a name.
